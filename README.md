# 📌 Система визуального оценивания вовлеченности учеников на уроках (system for visually assessing students’ engagement in lessons)

## 📝 Описание

Любой педагог согласится с тем, что удержать внимание класса на протяжении сорока-сорока пяти минут — это невероятно сложно. Даже опытный учитель не может одновременно контролировать тридцать человек. Пока он пишет на доске или объясняет сложную тему, остальные могут отвлекаться: кто-то смотрит в окно, кто-то переписывается под партой в телефоне, кто-то спит на задней парте. В итоге учитель оценивает общую атмосферу на уроке чисто субъективно, и реальная картина не видна. В эпоху современных технологий возникает вопрос: можно ли использовать современные технологии не только для контроля и безопасности, но и для реальной помощи учителю? Данный проект посвящен разработке системы визуального оценивания вовлеченности учеников с помощью ИИ-камер, которая способна стать объективным цифровым помощником для современного преподавателя.
